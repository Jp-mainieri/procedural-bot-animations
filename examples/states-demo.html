procedural-bot-animations

A silhouette-plus-eyes definition rendered and driven entirely by this repo's own engine — weighted moods, one-shot reactions, and gaze with saccade/pursuit physics. Move your pointer over the bot; mix moods and fire reactions below. These shapes are Open Bot Avatar examples, used only as modeling input (see berry-live/berry-demo.html for a faithful port of DevBerry's actual multi-part Berry, leaves included, which this generic single-silhouette engine does not attempt to reproduce).

Vanilla JS + ES modules, no build step to view this file — open it through a local server (ES module imports need http, not file://), e.g. npx serve . from the repo root after npm run build.
