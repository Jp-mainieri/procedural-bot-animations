Berry simulator GitHub npm

A silhouette-plus-eyes definition rendered and driven entirely by this repo's own engine (src/) — weighted/blended moods, one-shot reactions, and gaze with saccade/pursuit physics. These shapes are Open Bot Avatar examples, used only as modeling input — this engine never calls its renderer. For a character with separate moving parts (leaves, limbs), see the Berry simulator instead, which this generic single-silhouette engine does not attempt to reproduce.

reaction: none

Shape (Open Bot Avatar example JSON)

Move your pointer over the bot to see the gaze follow it, with saccade/pursuit physics (src/gaze.ts) — not a plain damped follow.

Moods (toggle any combination)

Each mood is a full-weight pose delta, blended by weight (src/moods.ts) — mix "curious" and "sleepy" at once, unlike a single mood string.

Reactions (one at a time, queued by priority)

Closed-form curves of progress t, played one at a time with a priority and a staleness rule (src/reactions.ts's ReactionPlayer).

Vanilla JS + ES modules, no build step to view this file — open it through a local server (ES module imports need http, not file://), e.g. npx serve . from the repo root after npm run build. Respects prefers-reduced-motion (mood/reaction changes still show; the idle wander, breathing and blink loop stop).
