procedural-bot-animations

A procedural moods/reactions/gaze engine for a silhouette-plus-eyes avatar — the shape format from Open Bot Avatar, used only to model the shape — plus a typed state machine to drive it from real app events.

Open the live demo → Berry case study → GitHub npm 
npm install procedural-bot-animations

Weighted, blended moods

Mix "curious" and "sleepy" at once instead of a 3-string mood enum — each named mood is a full-weight delta, blended by how much of it is active.

Gaze + reactions

Saccade/pursuit/microsaccade eye physics, autonomous wander, and one-shot reaction timelines (bounce, fright, nod) with a priority queue.

Typed state machine

idle / thinking / success / error / loading / sleeping, or your own set, with timers and interrupt rules.
